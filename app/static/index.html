    本机连接 / SKETCHUP

    连接你的 SketchUp

    通过本机 MCP 桥接访问 SketchUp。检查连接只读取连接与模型信息；打开项目模型会启动或切换 SketchUp，读取并校验本会话的独立副本。

    使用你已安装的 SketchUp，并为该版本安装匹配的 K Studio Connector 或已有兼容插件。无需为了连接更换软件版本，插件已安装时，下方自动连接会打开 SU 并启动本地桥接；无需先手动打开副本。自动连接不会代装软件或插件。
    想手动连接 MCP？查看步骤 ↗
    1. 打开你要使用的 SketchUp 版本，保存当前工作，并退出群组或组件编辑。安装了多个版本时，先只打开你希望连接的那一版。
    2. 首次使用先打开连接器向导完成配对，再在该版本的「扩展程序管理器」安装 K Studio Connector 并重启。插件会尝试自动启动；未响应时点击 K Studio Connector → Start paired local connector。已有其他插件配置时按原说明启动，不自动覆盖。
    3. 回到这里，点击「仅检查 MCP」，确认桥接是否响应。这一步不会打开、切换或修改模型。
    4. 桥接就绪后，再点击「打开项目模型并连接」，绑定本会话的独立副本。MCP 可达不等于项目模型已绑定。

    使用当前明确配对的本机 MCP。若提示“未配置”，打开 K Studio 连接器向导完成配对。已有连接不会被自动覆盖，配对配置与实际原生连通分别检查。

    检测到软件不等于兼容性已通过。插件和建模工具的实际可用性需按版本检查；未验证的版本不会标为已支持。

    连接后仍需批准计划才会建模；如果你已批准计划并从执行流程进入，此处连接成功后会继续执行该计划。

    独立副本提示项目身份不匹配？

    检查模型来源与当前会话。确认后仅迁移独立副本的归属，保留几何和材质；原件不变，不会自动开始建模。

    交流与分析无需连接；开始建模前才需要连接。
    本机安装 / CONNECTOR

    安装 K Studio 连接器

    插件装在你选择的 SketchUp 里，本机连接程序由 K Studio 配置。不需要安装 Codex 或填写模型密钥。

    我的 SU 版本是否兼容？

    正在读取候选适配范围和本版原生验收记录；检测到安装不代表已支持。

    2. 让 K Studio 配置本机配对

    为本机通信程序和 SketchUp 插件建立配对，不是安装 SU 插件。首次使用配置一次，无需复制 JSON、填写端口或模型 Key。已有配置保留。本步不修改模型，也不证明原生连接通过。

    3. 在 SketchUp 中安装并启用插件

    先完成配对，再下载 .rbz，在所选 SketchUp 的扩展程序管理器安装并重启。已有可用插件先检查连接，不自动覆盖。下载文件本身不会安装或连接。

    模型连接

    连接模型 API

    选择 Key 所属的服务商；同一个模型在不同平台使用的地址和 Key 可能不同。

    填写服务商提供的 API 地址、模型标识和 Key 即可。保留此连接已保存的模型设置；新连接使用模型默认设置。支持 OpenAI Chat Completions 兼容接口，图片理解和工具调用能力取决于所选模型。

    Key 使用当前 Windows 用户的系统加密保存在本机，不显示在对话或报告中。切换服务商需要重新填写对应的 Key。

    打开所选服务商的 Key 页面 ↗
    快速开始

    先聊清楚，再开始建模

    1. 新建会话，上传、粘贴图片或拖入资料，也可以先直接提问。
    2. 简单说「请根据这些资料帮我建模」，与 AI 交流缺少的信息。
    3. 确认后点击「整理建模计划」，查看估算与范围。
    4. 批准之前按连接教学检查 MCP、打开独立 SU 模型。
    5. 批准后查看真实工具进度与截图，下载 SKP；继续对话可修改。

    支持图片、PDF、DOCX、TXT、MD、CSV、DXF、DWG。DWG 只保存原文件，需补带尺寸的 PDF/图片；扫描 PDF 需清晰截图。网址可直接粘贴，读取失败会提示补截图。聊天与计划不会改动 SU。

    确认当前计划可点击按钮，也可输入“按当前计划开始建模”。讨论、条件和新增修改会先更新计划。明确的局部修改会保留原模型与其他构件。

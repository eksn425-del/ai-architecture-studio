      本机连接 / SKETCHUP

      连接你的 SketchUp

      通过本机 MCP 桥接访问 SketchUp。检查连接只读取连接与模型信息；打开项目模型会启动或切换 SketchUp，读取并校验本会话的独立副本。

      使用你已安装的 SketchUp，并为该版本安装匹配的 Kongxing 插件。无需为了连接更换软件版本，自动连接不会代装软件或插件。
      想手动连接 MCP？查看步骤 ↗
      1. 打开你要使用的 SketchUp 版本，保存当前工作，并退出群组或组件编辑。安装了多个版本时，先只打开你希望连接的那一版。
      2. 若尚未安装插件，在该版本的「扩展程序管理器」安装匹配的 Kongxing 插件；然后在扩展菜单启动 Kongxing Local Bridge。
      3. 回到这里，点击「仅检查 MCP」，确认桥接是否响应。这一步不会打开、切换或修改模型。
      4. 桥接就绪后，再点击「打开项目模型并连接」，绑定本会话的独立副本。MCP 可达不等于项目模型已绑定。

      当前使用已配置的 Kongxing MCP。若提示“未配置”，还需由安装程序或管理员完成本机 MCP 配置；此窗口暂不提供任意 MCP 服务地址的填写入口。

      检测到软件不等于兼容性已通过。插件和建模工具的实际可用性需按版本检查；未验证的版本不会标为已支持。

      连接后仍需批准计划才会建模；如果你已批准计划并从执行流程进入，此处连接成功后会继续执行该计划。

      独立副本提示项目身份不匹配？

      检查模型来源与当前会话。确认后仅迁移独立副本的归属，保留几何和材质；原件不变，不会自动开始建模。

      交流与分析无需连接；开始建模前才需要连接。
      本机安装 / CONNECTOR

      安装 K Studio 连接器

      插件装在你选择的 SketchUp 里，本机连接程序由 K Studio 配置。不需要安装 Codex 或填写模型密钥。

      我的 SU 版本是否兼容？

      使用同一套连接协议，默认自动识别本机安装；多版本时才需选择。2019–2026 为候选适配范围，逐版本实机验收尚未完成。2010–2016 缺少目前模型保护需要的持久对象标识；2017–2018 的旧 Ruby 也不满足当前插件的全部要求，暂不提供完整建模适配。当前原生试用记录来自 SU 2024；检测到版本、插件文件、桥接响应和完成建模验收是不同状态。

      2. 在 SketchUp 中启用插件

      首次安装：下载 .rbz 文件，打开 SketchUp → 扩展程序 → 扩展程序管理器 → 安装扩展程序，选择刚下载的文件，再重启 SketchUp。已有可用同名插件时跳过本步，直接检查连接。下载文件本身不会安装或连接。

      下载 SketchUp 插件 (.rbz) ↓
      3. 让 K Studio 配置本机桥接

      这是 K Studio 与 SU 插件之间的本机通信程序，不是第二个 SU 插件。首次使用点击一次即可自动校验和配置，无需复制 JSON、填写端口或模型 Key。已有配置会保留，可跳过。本步不修改模型。

      4. 检查连接

      在 SketchUp 的「扩展程序 → Kongxing AI → Start Local Bridge」启动桥接，再点击下方检查。首次连接需同时打开 SketchUp 和 K Studio；插件启动后可自动连接。未响应时，在 SU 的「扩展程序 → Kongxing AI → Start Local Bridge」手动启动，再检查。检查成功后仍须连接当前项目模型，才可以建模。

      快速开始

      先聊清楚，再开始建模

      1. 新建会话，上传、粘贴图片或拖入资料，也可以先直接提问。
      2. 简单说「请根据这些资料帮我建模」，与 AI 交流缺少的信息。
      3. 确认后点击「整理建模计划」，查看估算与范围。
      4. 批准之前按连接教学检查 MCP、打开独立 SU 模型。
      5. 批准后查看真实工具进度与截图，下载 SKP；继续对话可修改。

      支持图片、PDF、DOCX、TXT、MD、CSV、DXF、DWG。DWG 只保存原文件，需补带尺寸的 PDF/图片；扫描 PDF 需清晰截图。网址可直接粘贴，读取失败会提示补截图。聊天与计划不会改动 SU。

      确认当前计划可点击按钮，也可输入“按当前计划开始建模”。讨论、条件和新增修改会先更新计划。明确的局部修改会保留原模型与其他构件。

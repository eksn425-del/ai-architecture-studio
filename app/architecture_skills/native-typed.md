# 原生语义建模

先读取 SketchUp 当前项目副本、模型修订和已批准范围。用 `sketchup_apply_parts` 提交一个明确的建筑系统。使用毫米和稳定的构件名称，实体、门窗框、玻璃和楼板各自可编辑。工作台按原生事务提交结果显示进度。

可用类型包括盒体、平面多边形的挤出、圆柱、恒定截面轮廓及矩形窗开间。楼梯先定各级标高和上下落点，适用时用样板阵列踏步，按核对过的接边分别建平台和栏杆。带孔直墙先验证一个真实洞口。现有工具表达不了的构造，向用户说明并保留对应范围的待办。

每次提交后核对部件的实际位置、尺寸、材料和连接。纠正前读取当前状态，只写已批准的目标。出现未知写入时先用工作台恢复，保留上一检查点。

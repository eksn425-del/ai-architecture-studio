# 验收与交付
最终几何修改之后，获取同一 revision 的 front、oblique、roof 三张原生截图，然后 kstudio_review_model。若任何视图落后，只补缺失视图，不为了刷新截图再改几何。截图 hash 与 revision 是证据身份，不是视觉质量分数。
逐项对原图：整体比例/层数、负空间、斜撑端点、阳台层次、屋顶退台、入口。把缺失或近似告诉用户；单图背面为推断。优先纠正建筑关系，最多两次有依据的修正，避免装饰来回改。
宿主保存和下载与原生重新打开是独立步骤。只有真实重开验证才可说已重开；工具返回 success、截图存在、自己觉得不错，都不等于独立验收。不得声称规范合规或施工可用。
最终回复面向建筑师/学生，简述成果、可编辑性、主要推定和仍有偏差的部位，使用产品现有模型下载入口。保留失败和阶段记录。若未完成，明确部分完成及恢复点。

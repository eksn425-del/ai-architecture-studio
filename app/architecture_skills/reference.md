# 参考图与建筑解读
K Harness 自有方法；来源：项目已记录失败与建筑图像重建工作流。用于推理指导，不代表量测或规范结论。

先读整体，再读系统：主体轮廓、楼层标高、开敞层、退台、入口、屋顶、主要构架、重复立面。每张图注明正面/侧面/风格/场地作用，不凭一张透视图断言背面结构。给事实标 observed、user 或 inferred，观察必须引用 source_N；估算宽深和层高要明确为估算。
把楼板和开敞楼层分别数清，屋顶女儿墙不自动算一层。用逐层标高表约束楼板、玻璃、阳台和斜撑。先识别最突出的 3–5 项特征，其他细节服从它们。用户没给尺寸时可以合理假定并在方案说明，避免无休止提问。

校正示例：一栋建筑中央有上下两组跨层斜撑，中间是连续后退露台。错误做法是逐层填满中央玻璃并加通高立柱。正确做法是把露台作为明确负空间；记录两组构架的起止标高/端点，分别建立语义部件。此示例不能覆盖其他建筑的实际图片。
输出简明的建筑理解和推定，保存事实图后保存给用户看的方案。禁止把自己的方案描述为用户已指定尺寸。

玻璃亭与架空住宅的易错反例：连续屋面下可能同时存在开敞门廊和封闭室内，不能把整个屋面投影都填成玻璃盒。先沿照片可见柱跨标出「有顶无围护」「有顶有围护」「露天平台」，再分别定位玻璃退界、入口和上下平台；透过空廊能看见树木不等于那里有透明玻璃。核查台阶是沿正面还是端部上升、每段连接哪两个标高，不能仅凭“在左边”把台阶放到建筑左端。先列观察依据，不把此反例的类型、尺寸和跨数套用于所有住宅。

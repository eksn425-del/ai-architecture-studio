# K Studio 一分钟宣传视频：可复用制作方法

以本次最后接受的 **v8 / 60秒 / 1920×1080 / 30fps** 为风格标准。记录制作方法和迭代判断，提供可替换素材的本地 Skill 与起步工程。**本目录和 Skill 不包含本次素材。**

## 下一次怎么用

将仓库的 `skills/kstudio-promo-video` 目录复制到本机 Codex 的 `skills` 目录，保留子目录结构。当前制作机器已安装；其他机器需另备 Python、Node、FFmpeg/FFprobe 和模板中固定的 Remotion 依赖。

对 Codex 说：

> 用 $kstudio-promo-video，按最终 v8 风格处理我这个新素材目录。做一分钟，重点展示这次新增能力，封面4:3。

提供：新素材目录、这次重点、真实能力/开发中功能和本次结尾文案。已经确定的品牌与节奏可以沿用；案例、人物、作者、活动与能力声明按新任务核实。缺关键镜头先列出缺口，不自动塞入旧案例。

## 外部具体问题

1. **顶层两条长边内层玻璃缺建，优先级1。** 原图2下、4上及5/8显示上厅有连续围护。当前长向只见木柱/边梁，上厅两长边在10800mm以上无相应侧窗组。原生 INNER_GLAZING 完整80个子件只覆盖两条长边0–10800mm；ROOF_SUPPORTS 分两页146件为42柱、2边梁、22端竖框、80端玻璃，未见上厅长边玻璃。不得把外侧缓冲玻璃当作内层侧窗已建。补窗需接既有端玻璃和屋顶边，保留屋顶曲面/高低关系。

2. **下部两端内层围护及门洞未完成，优先级1。** 当前低/中层端部可直视大厅，INNER_GLAZING仅两长边，缺内退端立面系统。坡道端来源1/3支持有入口围护；远端位置由图5/7约束，门窗细分需推断。外层两短端7200–13500玻璃实际上各10面已存在，不能误报为外皮整面没建。补内层端窗/实墙分区及真实门洞，保留源图要求的下层开放外廊。

3. **远端直梯只有72块踏步，缺完整梯段/扶手/接平台，优先级1。** 四面及近景显示三层重复踏步序列，没有对应梯侧防护和完整上下口。端梯横跨 x50500–52700，首层远端格栅及支承位于 x50000–54000、y0–20000，仍为整幅；近景可见梯段钻到板下，须局部测净空并给上口留正确洞口/落脚平台。不能以踏步顶标高接近楼层证明路线成立。端外廊x54000低层横边也未见连续护栏。梯位遵图5/7，未见细节采用相邻细白构造推断。

4. **上层平台仍有外伸余段，优先级2。** 源1/2上层主要收于矩形外皮内。现L2两侧、L3一侧仍有外伸平台；L2读回y=-6200/-4000及24000/26200，外玻璃y=-4000/24000，外伸2200mm为当前实测模型值，不是源图尺寸。后续应逐个核定哪段属必要转接，哪些是旧余段；缩回同时接顺门洞、回廊、坡道起终点，不能只删一块台板。最低坡道及原有低层开放露台单独保留。

5. **外廊、坡道及平台栏杆未完成源图细网形式，优先级2。** 目前主要为三道开敞横杆，缺网片、细边框及转角/开口收边；原图3和模型1/2显示细白护栏。沿两长侧、坡道两边和转台逐类处理，先验一个普通段+转角+门口样段再复制。短端上层玻璃围护与栏杆是不同系统，不统一堆加多排横框。现视图黑线含SketchUp边线，不能认定所有材料是黑色；脚本钢材为浅白。

6. **长侧内层门窗只完成连续玻璃面，入口和开启分格缺建，优先级2。** 两长侧各20面连续玻璃从地面直上10800mm，缺源图3入口门扇、门框、横档及图7对应的分层开口变体。现有三处上层外皮通道只开了外皮，不等于室内入口全部完成。按层/柱跨安排门窗，先解决交通再补外观框格；不凭照片自行补未证实的门数。

7. **缓冲区顶盖及幕墙节点过于简化，优先级3/待细化。** 当前四块100mm厚实心平板形成约4m宽整圈顶盖，幕墙为统一分格。原图2、5、6、8有轻薄框架、顶缘及通风边界；需区分透明、不透明和开启部分后补框、收边及端部回折。原图不够清楚，不能断定整圈必须改透明或给出精确开启扇数量。拉杆与通行区的冲突应在前述平台/门洞阶段一起检查，不能仅为画面干净任意删拉杆。

## 保留和已完成

不建议重建屋顶主体、改高低方向或复制成新模型。上下玻璃外框、下部混凝土框架、退进深度已有主要形态。13处环廊已是真实格栅并有独立横梁，不再泛称整块实板；板边、远端梯口及平台衔接仍需完成。两小圆洞护栏已建，不是本轮外部补建重点。室内挑空、帘幕、家具、圆洞内穿构件另列，不混进外部第一批修补。

## 建议实施次序（本次均未执行）

1. 确定内外两层围护边界及端部交通，先补顶层长边玻璃和两端内退围护；同步在需要进出的地方留真实门洞。
2. 整理上层平台余段、回廊/坡道门洞和拉杆净空；完善远端直梯、梯口及平台，补其缺失端边防护。只改这些依赖区域，不全楼改板。
3. 校准长侧分层门窗及端部外框的转角/横档，先做真实样段，检查玻璃/框/楼板节点。
4. 统一外廊、坡道及平台的细白网栏，先检查代表段及转角、门口，再扩展其余；保留已修通道。
5. 顶盖通风/边框、格栅收边、钢件色泽与玻璃显示等细节，最后逐面复核。

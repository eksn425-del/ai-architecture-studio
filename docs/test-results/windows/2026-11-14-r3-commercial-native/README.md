# R3 本机原生展亭，交付技术 PASS，商业门槛 PARTIAL

在一个真实 SketchUp 24.0.484 进程中，从隔离空白模型执行参数化展亭，先保存 r1，再把门廊从 800 mm 改到 1,300 mm，根 PID 36075 保持一致。Base、Frame 和 Roof 的深层几何材质指纹、持久 ID 和世界变换均与 r1 相同。另一次故意提交非共面四边形，原生派发前被拒绝。

真实 Edge 通过普通工作台入口下载了已验证的新 r2 SKP，使用同一个 SketchUp 进程重开，根、全文件深层几何与材质、显示三项指纹一致。六视图和相机旁证来自下载件。源角度文件为同一新样件的斜视，设计输入是 [书面尺寸样例](planning/fixture.json)。原始台账和 SKP 保留在 E 盘。实测此前的砖木工坊 r12 也能在同进程只读重开，历史 SKP 字节未变。

| 外部能力 | 适用情况 | 调用结果 |
| --- | --- | --- |
| 本机 SketchUp 连接器和类型化零件写入 | 规则实心盒体与矩形边界 | 实际执行并产生 r1、r2，两次带检查点 |
| ADAI、SAIE 等外部几何插件 | 样件无需外部几何引擎 | 0 包装调用，保留原生账本 |

首次浏览器夹具配置和取证驱动有失败，修正后复验通过。本轮几何由限定尺寸夹具调用，供应商请求为 0。新用户自然对话建模、独立源图保真、真实主体付费与独立干净电脑仍由各发布关卡跟踪。

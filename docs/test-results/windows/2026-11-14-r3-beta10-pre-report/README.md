# beta10 在原生报告生成前中断的恢复实测

隔离项目保存 r1，随即把门廊加深到 1,100 mm 并保存 r2。故障注入发生在宿主记录 r3 意图后、发送原生工具调用前。未启动 r3 写入。旧进程正常退出后，用实际 beta10 桌面界面按“恢复上轮修改前的模型”。新版启动新的 SU 2024 进程，恢复最后验证的 r2，保留 r3 缺少回执记录及源码哈希。首次建立夹具的连接失败另行保留。

在实际 beta10 客户端点击下载，选择 E 盘，然后同一窗口使用 SketchUp 打开下载文件。130,533 字节和保存检查点 SHA-256 相同，三个原生深层指纹与全部分组一致。六视图来自重开的下载件。无 B.AI 请求，本测试用合成尺寸验收恢复和交付。

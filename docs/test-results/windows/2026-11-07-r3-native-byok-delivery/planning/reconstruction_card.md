## 修改方案：只修楼梯栏杆立柱落地（不碰其他任何构件）

### 一、问题原因（据当前栏杆脚本推断，执行时先回读核实）
- 下跑立柱的 X 定位公式比该级踏面中心多算了 260mm，柱子实际落在**前一级**踏面上；但柱底标高却按后一级取，于是底部悬空 **150mm**。
- 上跑立柱同样偏了一个踏面，也悬空 150mm。两跑共 8 根立柱是同一个错误。
- 三组水平护栏（二层梯洞南侧、东侧、半平台）柱底已落在楼面 3000 / 平台 1500 上，没有悬空。

### 二、修法（只改 StairRailing 一个组）
**1. 踏面立柱回到自己那一级上**
- 下跑 5 根，放在第 1/3/5/7/9 级踏面中心：X = 3870、3350、2830、2310、1790；柱底分别 = 该级踏面顶 150 / 450 / 750 / 1050 / 1350（埋入 2mm 避免与踏面共面闪烁）。
- 上跑 5 根，同样 X = 1790、2310、2830、3350、3870（Y 不同）；柱底 = 1650 / 1950 / 2250 / 2550 / 2850。
- 柱顶按同一 X 处的斜扶手底面（顶线减 80）取值，做到**贴合、不顶穿、不留缝**；柱身仍 40×40。

**2. 两端补端柱，让扶手不再悬臂**
- 下跑低端 X=4000 落一层地面 Z=0；下跑高端 X=1660 落半平台顶 1500。
- 上跑低端 X=1660 落半平台 1500；上跑高端 X=4000 落二层楼面 3000。

**3. 扶手线型不动**
- 下跑 900→2400、上跑 2400→3900，两跑在半平台边 X=1660 处同为 2400 自然接顺，顶端与二层洞口护栏顶栏 3900 齐平。这次只修柱脚，不重画扶手坡度。

### 三、必须保留的（KEEP）
- 楼梯本体 InteriorStair：10 级×150 踢面、踏面 260、半平台 1500，一级不动。
- 二层楼板梯洞 X 200–4000、Y 5400–8000，不填、不缩、不平移。
- 墙体、全部门窗、屋顶、女儿墙不动；屋顶与女儿墙仍为独立部件。
- **刚改好的入口完整保留**：门廊雨篷前缘 Y=-2500、入口平台顶 ±0、三级台阶 -150/-300/-450 至室外地坪，本轮完全不碰。
- 只提交 StairRailing 一组；其余 11 组逐组核对尺寸与包围盒不变。

### 四、改完怎么验证
- 回读每根立柱的柱底、柱顶标高，与它所在踏面/平台/楼面的顶标高逐条比对，确认零悬空；
- 出正、斜、俯三张图，重点看楼梯井里的立柱与扶手交界；
- 模型整体包围盒应保持 X 0–12000、Y -3400..8000、Z -700..6600 不变。

### 五、仍属简化、可另议
- 扶手是连接两层楼面以上 900 的斜直线，首级踏面处净高约 750，比其他位置低；若要全跑统一 900 净高，需改扶手线并重接两端水平护栏，可下一轮单独做。
- 仍不做玻璃栏板、柱脚底板、抱箍等精细节点。
- 本方案只是改模型前的文字说明，不构成规范或施工合规结论。

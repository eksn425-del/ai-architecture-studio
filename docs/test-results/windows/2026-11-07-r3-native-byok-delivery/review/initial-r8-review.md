## 入口门廊：缺失平台，不能通过

图片中前缘三级台阶与主体门之间是明显白色空区，雨篷下未见一块连接门槛的地坪面；仅有双柱与上方雨篷。这个判断并非仅据包围盒：它同时得到可见画面、构件清单和相对位置支持。

- 主体 GroundSlab 仅覆盖 X=0..12000、Y=0..8000，顶面Z=0；正门 G_Door_Front 在Y=60..140，底Z=0。
- 前阶 EntranceSteps 到Y=-2000终止，最高Step_1面Z=-150；其外侧逐级为Z=-300和-450，300mm进深。
- EntrancePorch只列出Canopy及两根Column，没有Porch_Platform/Porch_Floor。雨篷跨Y=-2000..0，不能当作下方可行走地面；柱也不能填满该空区。
- 所以台阶最后一级与主体前缘间仍有约2000mm进深的未记录通行平台，尚差150mm上升到一层Z=0。按现有可见模型，它是“台阶+柱+雨篷”，没有完成从台阶到门的路线。

局部纠正目标应是让门廊有明确可行走的平台顶面Z=0，连续连接Y=-2000至主体门前Y=0，并与现有最高踏步形成最后150mm级差；平台宽度/柱脚关系按已确认门廊范围核对。保留主体、门窗和其余分组。平台的实际面边界及门槛必须在修后照片/原生读回验证，不能只添加一个宽泛组名。

## 内部楼梯：现有证据不足，不能把2850当成必然缺一级

外部斜视图被实墙/屋顶遮挡，没有足够画面判断内部踏步、平台、洞口和上下出入口是否连续。`horizontal_stair_faces`仅给每个水平面的Z与面积，没有XY顶点、朝向、邻接或洞口轮廓；同一Z还出现重复水平面，可能包含踏步底面，不能直接当作可踩踏面清单。

已知读回：下跑Z=0..1350，半平台板Z=1350..1500，上跑Z=1500..2850；二层板Z=2850..3000。150mm竖向节奏与方案3m层高相容。上跑末级顶Z=2850到二层完成面3000的150mm**可以由二层楼板边缘作为最后一级踢面**；下跑1350到平台1500也可以是正常最后一步。因此仅凭这两个150mm高差，不能认定楼梯悬空或漏一级，更不能盲目加台阶。

实际须核对以下未证实关系：

1. 下跑第一步能从一层进入，平台与两跑在XY上形成可走连续路径，无墙体/栏杆封堵。
2. 上跑末端应接到Z=3000楼面边缘，洞口不能延伸到使落脚处仍为空。`Level2Slab`整体bounds不能证明4.0×2.6m洞口真实存在或位置正确。
3. 上跑范围Y=6800..8000；后墙GroundWall_Rear覆盖Y=7800..8000、Z=0..3000，存在200mm包围范围重叠。半平台也伸到Y=8000。这是墙/梯干涉风险，**尚非面拓扑碰撞定论**，需顶视剖切或墙面实读回确认。若后墙确实未开洞/退让，应把可行走净宽与墙内边界对应起来。
4. 二层东侧Guard_Level2_East止于Y=6800，而上跑Y=6800..8000，几何范围看上去给上跑留了出口；但缺少真实端点/栏杆构件形状，不能据此断言出口畅通。

判定为 **UNVERIFIED / NEEDS_NATIVE_INTERIOR_EVIDENCE**。建议父代理后续采楼梯剖切或内部视角、下跑起点/半平台/上跑终点三处近景，加楼板洞口实际面轮廓与关键踏步XY范围；这是证据建议，本评估未执行任何建模或相机操作。

## 其余方案核对

主体12×8m、二层板顶Z=3000、屋面结构顶Z=6000、女儿墙顶6600与方案表一致；门、墙、楼板、楼梯、栏杆、雨篷、台阶、屋顶等语义组名确实出现在审计中。这仅证明已记录分组及外包尺度，不能证明实体、洞口、材质、拓扑或保存重开一致性。

方案首段写“每层净高约3m”，但后表采用3m层高：一层板底2850、二层屋面底5800，因此相应净空约2.85m与2.8m（尚不含任何吊顶）。若用户真实要求为层高3m，这一模型约定可解释；若要求净高3m，方案与结果需要澄清。当前不以此擅自扩大几何修改范围。

方案还提到“4×5.2m通高展厅空间”和“屋顶上人”，现有外观/整板bounds不足以验证通高洞口或上屋面通路，不能发布这两项已完成。它们不是当前12×8m两层展亭最小用户要求的自动新增任务。

### 基本衔接已有可见支持，不能再笼统称“楼梯没有接上”

- 下跑近景能看到踏步依次上升，最高处接到中间水平平台，平台转至上跑起点。画面未呈现横跨整个路径的断裂或缺一段平台。上下两跑与中间平台的基本U形关系可见。
- 上跑出口近景从二层看向梯段，前景二层地面与最高一级之间有明确连续边缘，没有跨宽度悬空缝；左侧洞口护栏止于一边，右侧是墙面，出口未被横向栏杆封死。基本“末级→二层地面”连接有直接视觉证据。
- 这支持此前对2850→3000关系的谨慎判断：不能把楼板作为最后一级的150mm差值简单当作漏一级。维持原尺寸证据，不要求盲目加踏步。
- 下跑最底端与一层地面完整接口仍被图片边缘裁掉，梯段净宽/净高、后墙200mm重叠究竟是实心干涉还是贴墙边界仍不能从透视图测定。新的两张图支持基本衔接，不等于全路径拓扑或精确通行净空已验收。

### 栏杆构造有明显未完成细节

下跑近景中，数根深色栏杆立柱的下端清楚悬止在踏步侧面之外，能看到柱端面；它们没有可见的落地/落踏步连接、侧向支架或基座。上跑也有柱端停在踏步之外的同类观感。现有近景可以认定**支承/固定构造没有被表达清楚，呈悬空外观**，而不能仅凭柱端与某个Z值相同就判连接完成。

中间平台处两条斜扶手也没有呈现顺畅的转接收口，黑色端头在转折区交错/中断；图片遮挡限制了具体端点测量，先标为需局部核对的细节缺陷。此处不把视觉上端头未连接升级为结构安全结论。

建议后续只在StairRailing内明确选择一种一致的固定逻辑：柱脚实际接到对应踏步/平台，或有可见的侧向连接构件，并连贯处理平台扶手转角。保持楼梯/楼板/墙体KEEP，不以此扩大成全楼重建。本评估未发出修改调用，也不将建议视为用户批准的新工作。

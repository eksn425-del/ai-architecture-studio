## 门廊修复的实际变化

r8图中台阶与门前存在约2米空区；r9斜视、正面和侧面都能看到实质平台填补该区。尺寸回读显示`EntranceSteps/Porch_Platform`为X3800..8200、Y-2500..0、顶Z0；最高`Step_1`到Y-2500、顶Z-150，后续三级面按150mm级差衔接；主体一层顶面Z0、门口在Y0附近。因此图片+实测共同支持“从台阶到平台再到门”的基本连续性，且门廊比原案外延0.5m。平台不仅是新增组名。

两根柱改为底Z0落在平台上，雨篷到Y-2500、顶Z3000；建筑主体仍12×8m。独立KEEP显示其余10个组几何/材质哈希完全相同，局部修改范围符合保留约束。外部场地及无障碍路线不在本轮场景中，未验收。

## 楼梯：基本连接可见，栏杆与背墙问题保留

内部近景可见下跑至半平台再到上跑的关系，上跑出口前景二层地面与最高踏步形成连续边缘，没有横向栏杆封死出口。末级Z2850到完成面3000可由楼板边缘作最后一级，不能据150mm高度差单独宣称漏一级。

但多根黑色栏杆立柱下端悬止在踏步侧面外，柱端可见，没有表达底座或侧向支架；平台处扶手端头转折不完整。最终r9内部图与初始同类缺陷一致，栏杆修改没有提交，不能将“方案已批准”写成“已修复”。精确净宽、净高、底部入梯完整接口没有充分量测，不作合规推断。

最终背立面图还可见室内楼梯阶梯轮廓出现在背墙外观面。此前dimensions显示梯段及平台伸到Y8000，而后墙占Y7800..8000，两者有200mm包围范围重叠；图像进一步支持存在穿插/共面边线问题，确切实体交集仍待原生面拓扑核对。它必须作为质量问题保留，不能仅因前面斜视看上去完整而忽略。

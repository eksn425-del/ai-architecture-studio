## 3. 推断（不可见部分，最简连贯补全）

- 背立面/西立面为白色抹灰 + 细框窗的风格延续；背立面不做镜像假阳台，不加装饰。
- 东立面底层除入口门外不加窗；二层仅上述 1 樘宽窗。
- 首层室内仅做可见家具（L 形沙发组 + 茶几 + 餐桌椅 + 盆栽 + 挂画），不做隔墙、不做楼梯；二层室内不可见，保持空壳；阳台见单椅/长凳 + 花盆 2~3。
- 屋面为单层浅灰卷材，坡度约 1.5%，坡向背侧，女儿墙内收水；不设天窗、不设屋顶设备（图中未见）。
- 勒脚：白色抹灰以下 0.30 高浅灰基座带，与铺装衔接。
- 框架、把手、灯具等小件按估算，细节级别到"近看合理"为止。

## 4. 建模范围

- 做：场地（铺装 + 草坪）、两层主体壳、平屋顶 + 女儿墙、阳台板 + 玻璃栏板 + 花盆、按第 2 表列出的全部开口（真实缺墙，不做"玻璃贴连续实墙"）、木格栅条阵列、入口门 + 雨篷 + 台阶、图中可见室内家具、材质分区。
- 不做：树木/绿篱/环境、结构配筋、内部隔墙与楼梯、家具细纹理、真实材质扫描。
- 室内：仅可见家具；场地：小范围铺装 + 草坪，无园路系统。

1. 持久文件：`scripts/build_villa.rb` 为唯一重放基线（替换模式＝清空自身 owned root 后整份重建）；局部修改另写补丁文件、复用同一 script_id 用编辑模式，禁止用补丁覆盖基线。

4. Pass 1（可识别主体）：场地、两层体量、屋面板 + 女儿墙（独立子件，不做全高封盖）、阳台板出挑、前立面首层大玻璃洞口 + 二层两樘推拉门洞口（墙体分段围合，洞口真实镂空）。
5. Pass 2（重复体系与深度）：按第 2 表实例化窗/推拉门模块（西 1+1、背 3+3、东 L2 宽窗 1）、玻璃栏板分段 + 立柱、木格栅竖条阵列（单一模块后阵列）、雨篷、台阶、入口门、室内可见家具、材质分区（白墙/基座灰/木格栅/深灰框/玻璃/灰屋面/大板铺装/草坪）。

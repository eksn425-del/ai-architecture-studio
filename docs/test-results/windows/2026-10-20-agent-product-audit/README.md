# Agent、API与活动预算工程检查

2026-10-20，北京时间。[中文产品判断与费用/部署方案](../../../PRODUCT_AGENT_AND_PILOT_REVIEW_2026-10-20.md)。候选分支继续为codex/release-prep-20261019，草稿PR #22；运行中的界面、原件、副本、视频素材与模型选择均未替换。本轮没有付费调用或真实所有者模型修改。

## 具体改变

- 通用API及独立Critic的返回模型、有效整数用量、截断/过滤检查，异常停止且不自动重试；模型标识只是供应商声明，并不能证明后台权重。
- 整批工具ID/参数/白名单先验证；不生成缺失ID，不重复执行已见ID。
- 执行意图先落盘，过程丢失后的未确认回执阻止下次请求/执行；不冒充已回滚。被拒Critic的已知用量仍保留。
- API上下文压缩保留旧用户原话及完整当前回合，保留磁盘历史。原话太长时不为了“压缩成功”删除要求。
- API的SU重建工作区只读字面检索，文件/行/SHA与不完整标志，扫描/文件/结果有限；非语义向量RAG，不假称Blender与原Codex都已启用。
- 供应商候选状态与价格明确区分文档/历史/当前版本未验收，离线活动预算计算器不冒充真实账本。

针对性套件171通过、0失败、0跳过；覆盖工具循环、真实LiteLLM本机拦截序列化、项目工作区、来源/视觉评审、Responses与API故障注入。最终完整Windows套件1054通过、22失败、16跳过。所有22个失败ID均在前轮环境失败清单中：14个Blender不可用/连接拒绝关联检查、8个Windows符号链接权限检查。**完整套件没有全绿**。依赖/跳过数量与昨天不同，本轮仅对比已保存失败ID，没有重跑整个昨天基线。

原始第一次完整尝试1033通过/30失败/16跳过，八个新增失败来自旧模拟响应缺模型/用量及工作区工具集合断言；修正夹具提供完整受控契约，未放宽生产校验。后续完整结果如上。原始日志和JUnit保留在本机runtime/product-audit-20261020，另复制到E盘交付目录，未把含本机路径的原始trace上传。

重点故障：返回错模型/缺模型、缺用量/bool/负数用量、输出截断/过滤、第二条工具参数坏时第一条零副作用、批内及跨响应重复ID、意图写盘失败零执行、写入后模拟进程消失再请求被阻止、Critic模型不符立即停止并保留已知用量、旧用户KEEP在模型摘要冲突时仍在原user角色。

新增请求检查依赖原有单用户/单写入控制，**不是分布式exactly-once、租户认证、付款系统或真实云成本熔断**。停止的本机会话要核对当前模型/回执并显式恢复，不能删掉记录后直接续建。

## 不同证据边界

供应商由受控模拟返回，效果计数器代替原生写入；真实SDK序列化在httpx本机拦截，不访问厂商。全量中的Blender测试若环境具备条件，使用其自有合成夹具；不使用用户已停止案例。没有新增真实SU、真实看图首轮质量、云端负载、多运营商网络、密钥托管/支付/额度发放或恢复演练PASS。

30fps影片和来福士素材未作为此次模型生成验收。历史Blender受控模拟、SU部分质量缺陷、剧院未完成和最终重开不确定状态都保留。

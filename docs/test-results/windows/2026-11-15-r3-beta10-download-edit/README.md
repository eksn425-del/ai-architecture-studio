# beta10 下载件的原生编辑和重开

用 Windows Computer Use 打开 [beta10 客户端原下载工程样件](../2026-11-14-r3-beta10-pre-report/README.md) 的独立副本，通过 SketchUp 管理目录选定门廊。用原生移动工具沿红轴输入 150 mm，保存后用同一 SketchUp 2024 窗口打开保存文件的另名副本。测试项目和证据位于 E 盘。

**本机交付副本可编辑性 PASS。** 原下载 SHA-256 与 SketchUp 的备份一致。编辑件和重开件均为 128,986 字节，SHA-256 为 06472a6e09072f9bd8861b926b1b3412db56b654216980c1a69905033a1c6d73。重开后门廊沿世界 X 轴移动 150 毫米，其余两个方向为 0。底座、框架和屋面完整原生子树一致。显示指纹一致，模型有 24 个面、48 条边和 8 个实例。

首次选到旋转控制点后取消。第一次读回时检查脚本将已是毫米的矩阵值再次换算。图像预检遗漏了输出目录恰好为已授权目录的情况。保留失败并修正检查，用同一已保存文件复验。此处样件由工程侧模拟操作，最新真实 B.AI 建模和独立首次用户流程仍待验收。

# beta09 实际客户端恢复、续改与原生 SKP 下载

本机 SketchUp 24.0.484 在测试展亭 r1 保存后收到了一个 r2 写入。测试器在原生回执返回后故意丢弃回执，保留失败现场和未确认状态。先用真实客户端“恢复上轮修改前的模型”按钮检查旧进程仍在时的保护，退出测试窗口而不保存故障编辑后再次点击。客户端打开新的副本，恢复与已保存 r1 一致的根、整文档几何材质、显示指纹。精确重复的旧源码被拒绝，后续经限定工具完成新的 r2，三个非目标系统深层 KEEP。

新 r2 由尺寸夹具触发。夹具验证原生读回并生成标准交付回执，再经 beta09 自带 WebView2 的真实“更新预览和下载”及“下载 SKP”按钮。下载件 130,581 字节，与检查点 SHA 一致，在同一恢复后的 SketchUp 窗口重开，三个原生指纹完全匹配。

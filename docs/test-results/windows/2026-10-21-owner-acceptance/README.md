# 用户验收与同图 Agent 对照（2026-10-20 至 21）

这次完成了原项目归档、产品修复、建筑学长正常界面首版/修改/中断恢复测试。代码候选已回归；未把它当作商业上线认证，也未重建用户的“验收”模型。

## 原 K Studio 测试

同一张正面照片；原始要求为“帮我还原这个建筑模型，侧面和背面合理推测”。随后用户要求环境/侧背面改造，再指出扶手、植物碰撞、道路长度与邻房。原项目有 12 条对话、3 次规划和 3 次执行，最终 root19/r7；7 次写入成功，20 次写入调用总计中包含被安全拦截及脚本失败的尝试。

六个主要回合记录合计 231 次工具调用、18 次失败、15,339,183 输入与 86,522 输出 token、3,282,609ms。意图路由与独立检查的额外消耗不包含在此六回合统计中，不能直接当作账单。20 次 writer、54 次标准视图、10 次视觉检查、35 次构件检查：调用数量不代表还原质量。3 次规划和 3 次写入阶段的 token/工具/错误分别保留在本机逐轮时间线。

观察：能在同一模型继续用户反馈，环境仅在用户提出后添加，原始图和修改截图分开管理；但代码生成出现无效方法 ID、路径格式、重复点、零向量、类型错误和复杂度上限，导致反复修复。最终独立检查仍指出扶手接头、树木和路面色差。原生交付收据仍为 `UNVERIFIED_NATIVE_REOPEN`；这次未补造历史三阶段验证。冻结的 275 个文件和所有原 SKP 均在本机；比较结束原项目 SKP 字节未变。

## 竞品正常使用对照

仅通过建筑学长电脑版的 SU 自动建模界面与其公开教程操作；使用已有账号额度，没有购买服务或读取私有程序实现。界面选择 gpt-6.1-sol，实际提供方、模型响应身份、内部上下文、token 账单和隐藏提示词未获独立验证。原图与 K Studio 输入像素一致；最初文案完全相同。局部修改沿用用户原文，反馈截图采用竞品自己首版背面，避免把另一产品的模型误作当前修改目标。

| 阶段 | 实际结果 | 记录的服务额度 |
|---|---|---|
| 首版 | 正常结束，原生 SKP、4 张预览、44 项来源映射；界面耗时21分30秒 | 1500→1358，142币 |

总计 415 建学币，不等于人民币或 API 成本。中断现场与恢复后的文件分别冻结。其最终脚本报告磁盘重开与几何摘要哈希一致；本方另用真实 SU 打开 E 盘归档副本并只读核对了活动文件路径。该摘要算法未审定，不能替代本产品严格全几何重放或完整源保真验收。

可见方法：读取技能→连接恢复→估算参数→分批构件生成→截图自查→局部补丁→保存/交付检查。其生成项目文件中有参数、构件映射、已知问题、阶段脚本和回读检查；说明这一次使用了项目文件记忆。无法据此断言内部实现了语义 RAG、独立 Critic 或宿主级 KEEP。首版状态曾保留 `visual_review: pending`，一些失败输出在界面仍带绿色工具图标；完成文字必须与真实收据交叉核对。

两边均能产生可编辑原生模型，均存在单图遮挡/背面推断、脚本失败与修复成本。竞品后期的植物和环境更细，K Studio 对话末版也明显改善；没有统一摄影测量真值、同相机盲评或多案例统计，不能宣称任何一方全面胜出。竞品“底层机制”仅作以上基于可见记录的推断。

## 本轮实际产品更新

- 会话按保存活动时间倒序；新建项目不再按 ID 字母排到中间。
- 底部控件、停止按钮、状态和提示放入同一个紧凑输入区。1440×900 实测对话550px、输入区171px，移动端无横向溢出。
- 活动按类别更新并合并重复提示，默认最多4行；原始记录/错误全部保留，可展开查看，不把一次失败覆盖成成功。
- 计划取消嵌套卡片滚动，全文在主对话滚动。新计划按当时正文和 SHA 保存到对应助手消息；后续计划更新不会改掉旧计划。已执行计划只显示一次，不能再次取得审批。
- 按钮和自然语言确认均使用原计划摘要、待批准身份、图片/模型校验。明确的已有模型局部修复可直接执行；新方案或扩大范围先更新计划，问题/条件/停止保持只读。修正“不要把楼板露出来”被误判成全局停止的特定情况；不删除真实用户文本。
- 唯一检测到的 SU 自动选择；已有插件/配置明确提示跳过安装直接检查。解释清楚 RBZ 在 SU 内安装、本机桥接由 K Studio 配置、两者不会因下载就自动完成连接。
- 同协议候选适配2019–2026；2010–2016缺少所需持久对象身份能力，2017–2018旧 Ruby 也不满足当前插件的全部要求。不把版本下拉列表当成测试通过；实机试用依据来自2024。当前安装包/分发授权与新电脑验证仍是单独发布条件。
- 新增只读正式版本检查，失败与没有发行版分别提示；不自动下载执行、不自动覆盖技能或连接器。本机继续用校验过的版本目录与回滚配置。
- 建模/检查规则明确楼板与墙面的坐标/退距、楼梯栏杆连接、植物碰撞、原图与推断立面、环境范围；补充准确方法 ID/路径格式提示。此部分属后续 Agent 行为改进，尚未用新真实建模证明消灭了这些几何缺陷。

## 测试与限制

- 最终完整本机回归：1064 passed / 22 failed / 16 skipped。22项为相同已有 Blender 不可用及 Windows symlink 权限相关失败；未新增失败类别。首次未设 UTF-8 的额外4项编码失败单独保留，修正环境后消失。
- 生产前端 Node 检查99/99；浏览器采用真实生产 JS/CSS + 冻结项目只读夹具，桌面/移动端通过，零修改请求，不能冒充一次新模型生成。
- 特定局部否定、暂停、条件、引用等114项相关回归通过（2项 Windows symlink 需额外权限，另在全量报告保留）；软件更新与计划快照也有直接回归。CI 独立复查候选。
- 未对 DeepSeek/百炼或新付费 API 发起试验；BYOK 的视觉、多工具、长上下文、断线/保存效果仍须按实际提供方分别验收。云端注册、多租户、数据库、原子额度与队列仍未交付，不把本地 JSON 工程对外当作可接几百人的 SaaS。

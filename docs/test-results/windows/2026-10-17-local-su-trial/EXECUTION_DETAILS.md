## 失败和质量结论

初次新增前端回归有8失败/21通过，原因是 Node 中文输出被 Windows GBK 解码；明确 UTF-8 后通过。最终545通过/13跳过只证明代码回归。

初建5次失败包括方法标识、目标路径、来源证据、一次编码命令和额外修正提交拒绝；局部修改2次真实高度校验失败均在记录中。首次下载控件定位因面板被收起而超时，观察面板后成功下载；没有伪称首次成功。发布整理期间一次只读文件检视也遇到默认 GBK，指定 UTF-8 后恢复；没有改动模型。

独立 Critic 最终 `NEEDS_FIX`：首层门头到阳台底的白墙间距过紧；原图室外铺地依本轮范围未做。背面/右侧是明确同意的合理推断。Critic 只接收原图/当时当前模型，没有接收 r3/r4 配对；宿主另行核对前后正面和六相机侧证。可供本机个人试用，不是完整保真或客户商业交付认证。

# 分阶段玻璃住宅回归案例

这是 K Harness 的案例与人工验收规程，不是 DeepSeek 权重微调，不是自动视觉合格证明。来源为本机 2026-11-07 实测发现的错误；实际结果另见当日 evidence。

参考：摄影 Lessismore2020，[Farnsworth House Exterior 1](https://commons.wikimedia.org/wiki/File:Farnsworth_House_Exterior_1.jpg)，[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。原图只在本机保留。本案例尺寸均为推定，不作为建筑测绘或设计规范认证。

## 实际观察到的失败

首轮把连续屋面下的开敞门廊填成玻璃盒，玻璃按每跨六等分过密复制；平台与台阶的方向、上下通行连接也不完整。单独验收“有柱、有玻璃、有楼梯”不足以证明图像还原与建筑空间正确。

## 后续同类测试应验证

- 先在方案区分有顶开敞、有顶围护、露天平台；玻璃样板只在封闭区应用，不重复到门廊。
- 先提交柱板屋面骨架，再提交平台、围护样板、重复系统和细节。至少三个可见的不同原生几何状态；每次有版本、原生保存与真实进度记录。
- 楼梯每段明确上下平台标高、端点、方向与净通路；不能只靠楼梯数量或截图遮挡判断连通。尺寸需说明为估算。
- 中途点击停止，已有提交保持；同一项目继续后 root 不变，先读实际状态，不整栋重放。取消不授权任何新操作。
- 局部修正只允许批准的直接部件，其余柱板屋顶与核心体需原生深层哈希保持一致；样板复用不能修改共享定义而伤及被保护对象。
- 从真实页面下载 SKP，再在原生 SketchUp 重开；比较完整几何/材质指纹。保存一致性与源图外观分别判定。
- 原始录屏从空白开始，保留等待、失败、停止和恢复。相机取景前后核对材质、显示、光照和几何，禁止预制显隐或假动画冒充搭建。

## 普通用户话术

1. “请按这张图建立可编辑模型，保留架空楼板、细白柱、玻璃分格、平台和台阶。尺寸可以估算并说明，先给方案。”
2. 在方案卡片实际点击批准；中途实际点击停止，随后“继续刚才已经批准的建模，保留完成的部分”。
3. “左边应该是有顶的开敞门廊，玻璃太密；平台和台阶应能从地面连续走到门廊。请给局部修正方案，主体柱板屋顶不变。”

不得为了让此案例通过而对所有建筑强行使用本住宅的尺寸、跨数或外观。新增案例应覆盖独立系统与不同负空间，保留失败样本，不能仅挑好看的截图。

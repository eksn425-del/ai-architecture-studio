## 真正需要外部输入的条件

下面只阻塞对应真实验证，不能遮盖上表中的普通工程：

1. **真实推理批次预算/使用授权**：本轮 R2 3.6 未建立新的剩余额度。来源和对照预登记、请求估算/次数/失败停止规则先完成，再提供一次明确批次。不能用旧 10 元或旧模型成功记录推断本轮剩余预算。
2. **另一个干净 Windows/合法 SU 环境**：用户已明确暂没有第二台。交付可自检安装包和独立验收脚本；本机新 profile 只能证明 profile 隔离，不能称干净机器。
3. **正式签名证书和可信发布者固定信息**：已有候选 updater 的本地测试签名只允许内部演练；生产私钥、证书/时间戳/可信指纹与分发授权须另外提供。
4. **真实身份提供方与商户沙箱**：需要 IdP issuer/client/回调白名单、商户测试 Key/签名密钥、经确认的价格/退款规则和真实主体资料。可先完成适配及本机真实 session 流程；不能捏造手机号/微信/QQ 登录已接入。
5. **域名、主机、TLS/DNS 与目标网络**：已有配置/部署/回滚脚本不是公网部署证据。正式环境需真实资源与授权；大陆成功率/延迟需从对应网络记录 DNS/TLS/下载/登录/余额/推理各段，而非一个 ping。
6. **尚未具备权利的公开资料**：发布私有建筑图片、原生模型或第三方素材需要适用授权；可先公开脱敏代码和工程结果，不能因需要证据而上传私人原件。

## 当前真实状态

- 有已保存的 GPT-6.1 Sol Low + Codex App Server 六视角成功模型，具备发展的立面、屋檐、玻璃、阳台和场地；不是零误差或无人值守商业验收。
- 国内 GLM API 已真实执行，但当前单图以及此前六视角实验还原质量失败/不完整。最新155项测试通过只说明软件回归，不说明质量合格。
- 当前 LiteLLM 适配器仍拒绝 Sol/Astra 的 Responses-only API 工具路线。开发机原生 Codex 成果不能作为独立 API 商品已成功的证明。
- E盘桌面安装和快捷方式可用；干净 Windows、普通用户从安装到下载以及连接器可分发方案仍需验收。

## 首个商品建议

Windows本地建模助手 + 本机SketchUp连接插件；官网先用于案例、下载、支持与预约。第一批只面向已安装受支持SketchUp的建筑学生和初级设计师。

交付承诺建议：用户提供1–6张同一住宅的参考图，得到有主要屋顶/立面/开口/材质分区、可以继续编辑和对话修改的SKP初稿。未知尺寸与不可见内部明确为估算/推断。

当前仅多视图Sol有发展的真实成功证据。先让相同证据在独立API路径稳定复现，再推广单图与纯文字。不要在广告中把开发者协助成果称为普通用户无人值守结果。

## 建议执行顺序

1. **独立模型链**：通过现有provider边界复用LiteLLM Responses或官方SDK最小适配，验证Sol API的图像、工具、思考与续跑。先做免费协议测试；任何真实API调用仍需本轮之外的预算确认。不得悄悄借Codex原生登录或Astra替代。
2. **成功基线复现**：同六张图、同Skill、独立空白模型，比较原生成功路线与网站API。由人看源匹配截图和SKP，不接受模型自报PASS；先测建筑质量，再决定经济档。
3. **首次安装**：干净Windows/另一台电脑，完成受支持版本检测、可合法分发的连接器安装、API配置、空白项目绑定、停止续跑/失败恢复、保存下载。安装包必须自带所需运行时，不能依赖开发机隐含环境。Key重启后安全留存/明确重新输入方式也要解决。
4. **五人小内测**：每人两个住宅案例，至少一个陌生案例。记录连接失败、建模失败、耗时、费用、开发者接管和用户是否保留结果；人工帮助单独列出。
5. **再试收费**：建议实验性测试99元/30天体验含一次安装辅导、用户自备API；这是待验证报价，不是竞品价格或盈利预测。若多数人不愿配置API，测有明确额度的小包次，再考虑代付推理。别提供无限建模或永久免费人工支持。

拟定内测门槛（尚未达到）：10次尝试至少8次无需开发者改代码完成连接→批准→建模→下载，至少7次用户愿意保留并继续编辑；原文件误改为0；显著楼层/屋顶/开口错误、破碎漂浮不能计质量通过。记录分母和失败，不凭一个演示推断稳定性。五人试验只用于早期学习，不是统计可靠性证明。

## 低成本获客与成本记录

先访谈/招募同学和初级设计师，了解最费时的建模任务、接受的初稿质量、安装障碍和付费意愿。官网收预约，不先投广告。发布三条真实产品录像：首次安装到模型、源图与可编辑构件对照、一句话修改同一模型。保留真实耗时与模型名称；演示资料应可公开使用。

每个案例记录实际provider token/账单、工具次数、重试、耗时和人工支持分钟。单位有效交付成本 = 全部尝试的推理费用（含失败）/合格交付数 + 分摊售后与支付成本。BYOK只降低我们代付的推理支出，不消除用户费用或我们的安装支持成本。

近期首要动作：独立Sol API复现旧的好模型，其次让五位新人完成全过程。营销定位可以先验证；大规模付费宣传应等质量与安装门槛通过。

# K Studio R2 候选版使用说明

本文适用于 R2 本机候选；历史 `USER_GUIDE.md` 的单模型、旧插件和旧源码启动说明不代表当前交付。支持范围以本次安装包的版本、SHA、已测 SU 清单和已知限制为准。本机通过不等于所有电脑兼容；官网未公布有效包时不能从占位链接下载安装。

## 打开与保存自己的 API

完整保留安装包目录及其 `_internal` 等依赖，从安装后的 K Studio 桌面图标启动，不单独搬走 EXE。本机 BYOK 不要求登录云账户；本机项目不会因为云账户未配置而被删除。需合法安装验收范围内的 SketchUp，客户端不包含 SU 许可证。

打开输入框“模型设置 → API 连接”，填写服务商给出的 HTTPS Base URL（例如其文档中的 `/v1` 根地址，不是 `/chat/completions` 全路径）、准确模型标识和该服务商 Key。支持 Chat Completions 或高级 Responses，选择供应商实际支持的协议与推理档位。高级能力声明只表示自报；保存成功不是图片/工具/流式/建模验证通过。

Key 由同一 Windows 用户 DPAPI 加密保存，重启后保留，密码框不会回填。更换地址/模型时重新核对凭据和能力；不同服务商的 Key 不通用。删除连接会清除该保存配置，供应商端撤销仍应在供应商管理台完成。换 Windows 用户/电脑或重装系统不能保证解密旧凭据，需要重新添加，不要把 Key 写在聊天或截图中。

侧栏“账户与额度”仅在运营者配置真实云服务后使用。登录时打开 HTTPS 授权页，核对与本机一致的设备验证码，再明确授权。网站登录本身不会自动授权这台电脑。平台模型和 BYOK 在此明确切换；平台 Key 留在服务器。BYOK 供应商费用由你支付，K 服务费只有公布并明确确认后才适用；未知费用保持待核对。已选平台模式时，先到账户切为 BYOK，再到 API 面板改配置，避免静默换模型。运行中不能切换或退出账户。

## 连接 SketchUp

1. 先保存自己的原件，并准备独立副本。在输入框右侧选择“建模工具 · SketchUp”，打开连接向导。
2. 选择实际 SU 版本。候选年份、检测到安装、已做原生验收是不同状态；不在本版支持清单的版本不能据此承诺兼容。
3. 按向导配置本机配对，再下载真实 `.rbz`。在所选 SU 的扩展程序管理器安装 **K Studio Connector**，按要求重启 SU。插件加载后尝试自动启动；未响应时用 **扩展程序 → K Studio Connector → Start paired local connector**。
4. 回到向导做只读检测，核对当前文档路径与目标会话。配置存在不等于桥接可达，可达不等于文档匹配；成功状态也不是建筑质量验收。
5. 有旧插件/连接配置时先保留并检查；不要覆盖正在使用的配置，不在一个任务中切换 SU 文档。端口占用、多实例或文档不符时停止写入并按向导诊断。

首次安装插件可能需要在 SU 内操作一次。K Studio 不应声称网页下载 RBZ 已经完成 SU 插件安装。客户端后端的 loopback 地址与连接器只供本机，不开放端口给其他电脑。

## 正常建模、停止与恢复

新建会话，上传有权使用的建筑参考图，用自然中文讨论层数、尺寸、关键构件和保留范围。没有实测尺寸时，检查 AI 的估计与遮挡推断。批准当前方案后才执行几何；输入框有新增要求时先更新方案。

运行中使用界面的停止按钮。停止是请求后续工作停止，不表示已经写入的几何自动回滚；等待实际状态回传。不要重复点击继续、强杀 SU 或切换目标文档。正常关闭桌面时，如仍有任务，按提示先停止并等待；窗口不能用“关闭”来假装任务已完成。

失败后保留当前模型、对话与最近成功提交，查看具体错误。若是连接中断或提交回执丢失，先重新只读核对当前文档/版本，再使用系统给出的继续或检查点恢复入口；不要整轮重复建模。只有已保存的检查点才能恢复；“停止”“重试”“恢复上轮修改前模型”是不同操作，恢复会改变当前副本，应先另存需要保留的结果。没有可验证检查点时，应保留副本并提交脱敏诊断。

## 下载、备份与反馈

打开“模型与文件”，下载当前可用 SKP，并在 SU 重新打开这个实际下载文件。核对主体外形、构件/分组、材质、目标修改和保留部分。保存/下载成功不代表外观、规范或原生重开已通过。施工、结构和法规判断需要专业复核。

关闭任务和程序后备份完整数据目录，而不仅是 EXE。默认桌面 profile 为 `%LOCALAPPDATA%\KStudio`；安装快捷方式若设置了 `--data-dir`，以快捷方式实际目标参数为准，老安装常在其 `data` 目录。项目通常在该 profile 的 `runtime\projects`，连接和账户凭据在各自加密配置目录。保持副本的原始层级，不分享加密凭据文件；完整数据备份包含私人资料，应受控保存。

反馈附版本号、实际 SU 版本、短复现步骤、时间和脱敏错误；不要附 Key、Cookie、访问令牌或未经授权的模型。原生建模失败和服务商返回成功应分别描述。

## 更新与卸载

通过“使用说明 → 检查软件更新”查看真实结果；更新地址/签名尚未配置时不会凭空有新版。更新前保存模型、停止任务、退出程序并备份数据。只使用发布者正式提供且 SHA/签名匹配的完整包；保留上版供回退。`git pull` 更新源码不会更新桌面 EXE。

候选版本未宣称具备 Windows 系统注册的完整卸载器。若为独立目录安装，先退出 K Studio 与相关运行任务，备份数据，删除该版本程序目录和快捷方式即可保留数据；**不要删除 `data`、自定义 `--data-dir` 或用户模型目录**。需要移除 SU 插件时，从 SU 扩展程序管理器卸载 K Studio Connector 并重启；不要删除其他插件。若要彻底清除账号/API，请先在应用退出账户/移除连接，并在云端撤销设备和供应商侧撤销 Key，之后自行决定是否删除备份数据。

本版公开部署、真实商户/IdP、另一台干净 Windows 和其他 SU 版本仍按总验收记录注明的边界处理。运营参数由部署者按 `deploy/ENVIRONMENT.md` 提供，普通本机用户无需安装数据库或 Docker。

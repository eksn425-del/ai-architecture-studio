## 分阶段施工与检查
1. 主形：先塔楼、各段退台、左高楼/沿街翼及各自屋顶，再简化右邻楼；与原图同视角对照全部高低端点及街角比例。

3. 复制及变体：按实际层数/跨数复制，另做露台、凹阳台、首层通透段、实墙窗格，不复制成整面均质玻璃。
4. 收尾：先材质与栏杆，再摆放独立可复用植被；植被不得侵入建筑占用体积或阻挡门口，树冠与实际栏杆、屋面逐项检查。环境最后独立添加。
5. 每次写入后对照源图和正/后/左/右/屋顶/斜视六向；先修体量、屋顶和主要洞口，再修细节。需真实模型回读与独立复核。

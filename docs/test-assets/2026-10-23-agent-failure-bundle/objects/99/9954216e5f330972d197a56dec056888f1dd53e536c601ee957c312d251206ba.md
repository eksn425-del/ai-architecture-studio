## 建模范围

## 建模步骤（按阶段顺序，不再逐项确认）
1. **主导形体（primary_form）**：10 层楼板 + 正立面一次连续墙体批量矩形洞口（9 层 × (1 凹阳台洞 + 2 玻璃洞)；首层 2 洞：入口玻璃 5 400、卷帘 4 150）。凹阳台为真实 1 500 深凹陷（内墙 + 侧返墙 + 底板），不用贴面。
2. **代表模块（representative_module）**：先做一个标准层，读回核对：阳台洞 3 200 宽 / 2 500 净高、玻璃洞与竖梃对缝、板带 600 高不压洞口、阳台底板与侧返墙闭合、壁柱转角不破面、外墙外皮不被楼板穿透。
3. **复制（replication）**：阳台、窗型、栏板、窗帘、竖梃按同一参数阵列到 9 个标准层；左右/背面按各自推断窗型复制（左面含阳台列）。
4. **变体（variants）**：首层入口玻璃 + 门扇 + 卷帘、屋顶层（女儿墙 + 栏杆 + 种植槽 + 乔木）、背面服务门。
5. **收尾（finish）**：材质分带（浅米灰混凝土 / 略深边缘 / 低铁玻璃 / 米白窗帘 / 银灰金属 / 深绿植被）、细部收口、六视图 + 与源照片同角度对比截图 QA。

# 本轮转角连接核对

原生r16边界核对：L06、L14转角底板顶面与前玻璃栏杆底面同标高，AABB轴向间隙0。跨父组的栏杆/扶手和凹口顶板/上一层楼板关系，工具因缺少祖先变换证据标为unverified，不能宣称实体连接或通行验收。

源图方向近景未见悬空栏杆或明显植物穿墙。构造脚本中：底板80厚，栏杆底位于底板顶；栏杆顶接扶手底；凹口顶板到z+2880，与保留的下一220厚楼板底同高。普通楼板实际侧/后角仍内收50mm。

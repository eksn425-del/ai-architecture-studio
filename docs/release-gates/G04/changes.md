# G04 · 实施记录

- 新构建提供两个安装目录选项，沿用已经注册的程序位置和资料位置。旧版没有资料注册项时显式选择既有资料，避免静默使用新的空白目录。
- 程序与资料相互隔离，Windows 设备别名、目录重解析及相互嵌套路径拒绝。版本槽、互斥、原子版本指针和深路径规则继续生效。
- 卸载只操作当前注册的安装版本，保留独立资料、已知所有权与较旧版本槽。安装不改变 Windows 全局 TEMP 或账号路径。
- 发行静态素材阶段排除权利未确认的展览内容，包括 9 张图及其 3 个页面文件，源文件原样保留。构建附带实际正式 Harness SDK、Node、SketchUp 连接器，未继承原账号的 API 或图纸。
- 使用独立全载荷 NSIS 验收身份进行本机演练，其二进制的注册 ID 与通用包不同。

# G08 · 实施记录

- 每个环境使用独立的 Compose 项目、卷与网段，信任各自 Caddy 私网地址。公网端口仅来自 Caddy。
- 构建把源码 SHA 写入 OCI revision 和镜像内文件，`/health/ready` 返回实际 schema、运行环境和镜像版本，运维检查独立对照。
- 首次部署开关全关的 production 也需要显式选择。开放生产开关须关联候选 SHA、官网域名、真实关卡记录、签名安装包及负责人私有授权。
- 应用回滚要求确定的旧镜像摘要，先由旧程序只读检查当前 PostgreSQL schema、账表和 Vault。通过才切应用/维护服务。
- 部署源包包含可审查构建源和依赖清单，记录清洁态与版本。

## 交给真实试用者的任务

1. 从获准测试地址了解概念设计承诺、下载签名安装包，按向导选择程序和数据位置。
2. 用测试账号登录，在客户端打开建模工具或首次连接引导，选定 SketchUp 2024 的项目副本。报名试用时注明由自己连接 API 或使用平台模型。自己连接时，费用由供应商向自己结算。
3. 新建会话，上传允许使用的建筑参考，按通常说法提出一个概念建模需求。检查并批准建模方案。建模后只要求修改一个构件并核对其余部分。
4. 在“模型与文件”下载 SKP，在 SketchUp 重开、选中并调整一处可编辑构件。保存后再重开。报告能看见的差异、接边、材质和分组问题。
5. 在至少一次故障或取消时保留当前工程，核对通知、已保存版本、余额和申诉入口。安装更新后复验项目，卸载时保留用户文件。

每次任务保留相同步骤、实际耗时、人工介入次数、前后模型读回、真实钱包或上游用量记录和失败原因。三位用户中任何一位需要工程人员代做，按未完成计入。

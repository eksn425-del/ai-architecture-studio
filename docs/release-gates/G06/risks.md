# G06 尚待验证的风险

- 缺少经授权的真实 staging 平台账号、API 使用限额、允许向客户集成或转售的范围及实际账单。公开模型名和 1017 实际路由版本是两项不同信息。 [B.AI API 参考](https://docs.b.ai/llmservice/api/) · [B.AI DeepSeek-V4.1-Flash](https://docs-develop.b.ai/zh-Hans/llmservice/models/deepseek-v4-1-flash/)
- 当前建模回合标识由客户端生成。每用户日限额、钱包余额和平台全局并发承担最终准入保护。超出预占的实际供应商费用保留为待核对。上线前须核对供应商计价、图片和上下文边界及实际货币限额，再以有限批次验收。
- 未知用量会暂停该用户的新平台任务，原工件仍可用。以真实账单验证核对、补偿与恢复。

# 自己操作网站进行图片建模

## 当前可以做什么

本地工作台支持上传建筑图片、与 Agent 确认目标、查看参数计划、批准 SketchUp 建模、查看输出截图、下载可编辑 SKP，以及继续修改同一个项目模型。默认 Economy 路线为 GPT-6.1 Sol Low。

当前使用已配置的本地 Codex App Server 和 Kongxing 连接，不等于已经交付任意 API、自助账号管理或云端建模产品。LiteLLM provider 配置仍属于工程设置；不同模型的最终建筑质量需要单独验证。

## 第一次使用

1. 打开正在运行的本地工作台。本轮实例地址为 `http://127.0.0.1:8000/`。仓库标准 `scripts/dev.ps1` 使用 `http://127.0.0.1:8787/`，两个地址不要混淆。
2. 点击左侧 **新建建模会话**，输入名称后创建。已有项目在左侧 **历史会话** 中选择；刷新页面会记住选择。窄屏使用顶部会话菜单。
3. 页面只聚焦 AI 建模，默认 GPT-6.1 Sol Low。点击底部输入框里的 **＋ 参考图片** 上传图片，可以同时选择同一建筑的多个视角（最多8张），检查所有缩略图是否正确。请实际上传图片，而非只粘贴网址。
4. 在对话框说明目标，例如：

   > 按图片还原建筑，包含屋顶、立面开口、阳台与入口。没有实测尺寸，请估算并标明。允许推断背面，模型需要可编辑。

5. 点击输入框右下角 **↑** 发送。Agent 先描述理解，必要时询问尺寸或范围。回答问题后再次发送；没有需要补充的内容时，输入“按上述要求生成建模计划”。分析和规划阶段不修改 SketchUp。
6. 展开输入框上方 **建模计划与参数**，阅读尺寸、已知条件和估算。要改计划，点击 **修改参数**，输入调整内容，再点击 **↑**。参数卡是 Agent 保存的原文，卡内文字可能落后于当前会话状态；实际是否建模以会话回复和模型截图为准。
7. 保存并关闭其他 SketchUp 文档。点击顶部 **连接 SketchUp**，网站创建独立模型。已有模型显示 **重连 SketchUp**。如果出现其他文档的保存提示，先处理提示再继续。
8. 计划完成且项目模型已连接后，点击 **批准计划并开始建模**。这一步才允许修改 SketchUp。不要重复点击、刷新或同时从另一个页面控制模型；复杂回合可能需要数分钟。
9. 结束后点击右上角 **模型与文件**，侧栏的 **模型** 显示截图，通过 **下载 SKP** 保存结果。截图是真实视口图片；下方缩略图可以查看 Agent 留下的多视角检查截图，网页当前不是可旋转的 3D 查看器。
10. 在同一项目对话框填写具体修改，例如：

    > 右侧阳台太浅，请加深；检查背面和侧面，补齐窗框。最后用正面和背面截图自检。

    点击 **↑**，继续修改同一模型。若想只重新讨论参数，不立即建模，先点 **修改参数**。左下角 **?** 可以随时查看操作说明。

## 当前金山案例

左侧历史会话选择 **金山邻里中心 · 网站 Sol Low 实建**，即可看到已上传的两张参考图、对话、参数卡、实际 SketchUp 截图和 SKP 下载。这是已执行的本地案例，仍有与源图不一致的形体和细节，不代表正式 Direct Codex 同质量验收已经通过。

切换网页项目只切换项目资料，不会自动切换 SketchUp 活动文档。开始该项目的新建模回合前，使用其连接按钮确认独立模型。一次只操作一个 SketchUp 项目。

## 与建筑学长流程的关系

采用公开观察到的交互逻辑：输入 → 澄清 → 参数化计划 → 用户批准 → 工具执行 → 截图检查 → 连续修改。没有复制其专有实现、聊天记录或插件源码。

本轮补齐项目选择、步骤提示、参考图预览、参数卡查看、明确批准入口、修改参数入口、等待时长和下载入口。尚未实现工具执行事件的实时流式展示、后台任务恢复或多项目建模队列。等待时长不是 Agent 的工具日志，也不是完成百分比。遇到失败请保留页面错误和当前模型，不要把工具返回成功视为质量合格。

## 中断与恢复

等待时会立即显示你刚提交的消息，输入框锁定，避免重复发送和丢失下一条输入。复杂建模可能持续数分钟，当前仍不是后台任务队列。

若回合中断，网站保留执行线程、工具记录、已提交 Ruby 版本，并尝试保存当前模型与截图。中断记录明确表示尚未完成全部检查。看不到建筑、或本轮修改不满意时，打开 **模型与文件**，点击 **恢复上轮修改前的模型**；恢复的是本项目生成文件的副本。SketchUp 若出现保存提示，请先处理提示再重试恢复按钮。不能据此声称整个流程已无需人工干预。

恢复不会重建私人原文件。第一次建模尚未成功保存时可能没有可恢复版本，需要 Agent 从持久完整脚本恢复。继续修改时说清要修改的部分；模型异常时不要连续要求 Undo，以免撤销更早的有效几何。

常见问题

首发支持什么？

验收范围为 Windows x64 与 SketchUp 2024。已在开发机验证从讨论、批准到可编辑概念模型、局部修改及 SKP 原生重开。普通用户首次安装仍待验收。复杂照片的精确复刻属于实验范围。Blender、Rhino、Unity 及其他 SketchUp 版本暂未列入首发。

需要下载客户端吗？

建模与 SKP 文件保存在本机，桌面客户端负责连接 SketchUp。网站提供发行、账户、用量及支持入口。请从下载页确认软件是否开放及版本要求。

可以使用自己的模型 API 吗？

候选版支持在本机配置兼容 API，模型费用由对应供应商收取。平台模型和软件服务费用会在开放前另行公布。网络中断时，请先核对模型、服务商用量和订单状态。平台订单售后通过账户订单和支持渠道办理。

模型和图片会被发送到哪里？

建模操作在本机执行。选用的模型服务可能接收提示词、参考图或场景摘要。发送前请查看服务商与隐私说明。仅在账户中选择同步后，个人 API Key 才进入云加密存储。

SKP 可以用于施工吗？

当前范围是建筑概念设计。请使用项目副本，复核尺寸、构造接边、文件完整性和设计判断。施工文件、结构及适用规范需另行专业审核。
